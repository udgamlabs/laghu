# Laghu: training data, licences and credits

Laghu was trained from random initialisation by Udgam Labs on openly licensed datasets and on data we generated. The
model weights and our code are Apache-2.0. Each dataset keeps its own licence, and anyone who rebuilds our data accepts
each source's terms. Licences were read from each dataset's card on 2026-10-22.

**How each part is published**

| Stage | Tokens | In this release |
|---|---|---|
| Pretraining pool | 52.6B (40.0B token positions trained) | rebuild script (`udgam/build_mix.py --mix v3`), source list, seeds, decontamination index and per-shard manifest; not re-hosted |
| 32K stretch data | 1.0B | rebuild scripts (`udgam2/ctx32k/build_long32k.py`, `udgam2/ctx32k/build_repair_r3.py`, `udgam3/runs/ctx32k/build_ctx32k_data.py`); not re-hosted |
| SFT data | 41,467 training conversations | re-hosted at `udgamlabs/laghu-sft` with per-row source, generator and licence columns (MATH-train problems and FinePDFs document text are left out and re-inserted by a script) |
| Evaluation outputs | — | re-hosted at `udgamlabs/laghu-evals` per item where each model's licence allows, otherwise as scores |

The pretraining and 32K data are not re-hosted because their shards keep only the text: the per-document credit that
share-alike and per-file licences need would be lost. Every source is public, and the scripts rebuild the same data.

## 4. Evaluation outputs

Outputs of every model in our comparison are published per item where the model's licence allows it, with a notice per
model. MobileLLM-R1.5-140M and MobileLLM-R1-140M-base (Meta, FAIR Noncommercial Research License) and
nltower-100m-base (no licence) appear as scores only; we report MobileLLM results for noncommercial research and
acknowledge Meta's materials. Benchmark item text is included only for GSM8K (MIT), IFEval (Apache-2.0) and our own
test items; the other benchmarks (MMLU, WinoGrande, ARC, HellaSwag, PIQA, MATH-500) appear as item ids with a script that
joins the text from the pinned public versions.
